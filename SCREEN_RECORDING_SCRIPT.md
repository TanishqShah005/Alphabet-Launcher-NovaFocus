# Screen Recording Script (1–3 minutes)

Record on a real Android phone.

## 0:00–0:15 — Resting screen
- Show the live clock and date.
- Show the seven home/favourite apps.
- Point out the star, A–Z column and bottom dot.

## 0:15–0:40 — Slow drag
- Touch around the middle of the A–Z bar.
- Drag slowly upward.
- Show the curve following the finger.
- Show the enlarged letter bubble.

## 0:40–1:00 — Fast drag
- Drag quickly from near A toward Z.
- Repeat in the opposite direction.
- Make sure the selected letter and app list change while moving.

## 1:00–1:15 — Empty letter
- Stop on a letter that has no matching app.
- Show the `No apps` state.

## 1:15–1:30 — Release
- Lift the finger.
- Show the alphabet returning to a straight line.
- Show the clock and home list returning.

## 1:30–1:45 — Launch
- Select a letter containing an app.
- Tap an app.
- Show the real application opening.

## Optional — Bonus
- Show the launcher selection dialog by pressing Home.
- Demonstrate the dark theme.
- Demonstrate any additional bonus features added later.
