# GitHub Submission Steps

## Recommended repository name

`alphabet-launcher`

## First commit

```bash
git init
git add .
git commit -m "Initial Alphabet Launcher project"
```

## Feature commits

Keep meaningful commits instead of one giant final commit:

```text
Initial Compose project
Add installed app discovery
Add home screen and live clock
Add alphabet bar
Add curve interaction
Add letter filtering
Add app launching
Polish empty states and README
```

## Push

Create a GitHub repository and connect it:

```bash
git remote add origin <YOUR_REPOSITORY_URL>
git branch -M main
git push -u origin main
```

Do not squash the history before submission.
